# Natural Language Processing (NLP) 

1\. **Classification** : Predicting a single label/class from an input. 
- Sentimente Extraction, Intent Detection, Language Detection, Topic Modeling

2\. **Multi-Classification**: Labeling multiple parts of a text. It prediects multiple labels/classes. 
  -   Part of speech tagging, Named entity recognition, Dependency parsing, Constituency parsing

3\. **Generation** : Text-in, Text-out tasks where the output length is variable.
-   Machine translation, summarization, question-answer structure 

# Evaluation Metrics

## Classification Task

**Classification tasks** predict a specific category for an input. For the evaluation metrics about classification, there are accuracy, precision, recall, and F1 score. 

- **Accuracy** : This is the simplest metric, representing the percentage of total observations that the model predicted correctly.

- **Precision** : This measures how many of the model's positive predictions were actually correct. 

- **Recall** : This measures how many of the actual true labels the model was able to identify. 

- **F1 Score** : This is the harmonic mean of precision and recall.

**Why do we need to consider all of these metrics?** 

The metrics are essential because accuracy can be misleading when data is imbalanced (Accuracy paradox). For instance, if 99% of a dataset is positive, a model could achieve 99% accuracy by simply guessing positive every time without actually learning anything. Precision and recall help identify if the model is truly performing well on the rare 1% of negative cases. 

## Generation Tasks 

**For generation tasks** like machine translation or summarization, evaluation is more complicated because there are many correct ways to translate or phrase a sentence. Traditional rule-based metrics include BLEU (Bilingual Evaluation Understudy) and ROUGE. These metrics were used before the Transformer was introduced. 

-   **BLUE** (Bilingual Evaluation Understudy) is used primarily in translation to measure how closely a model's output matches a human reference text.  

-   **ROUGE** is similar to BLUE but often used for summarization tasks. 

# Evolution Toward Transformers 
 
 Before 2017, Recurrent Neutral Network (RNN) and Long-Term Memory (LSTM) network were the stanrad models for NLP tasks such as language modeling and machine translation. These models processe text much like a human, one word at a time, from left to right. However, this sequential processing led to the **'Vanishing Gradient'** problem. 

When training a model on long requences, the gradients are passed back through every step of the sequence. If those values (gradients) are less than one, the gradient vanishes to zero, leaving the model unable to remember or learn from the beginning of a long sentence by the time it reaches the end.

An RNN reads it one word at a time. Each hidden state is like the model's memery after reading that word. That is, the model's memory is the information stored in the model's hidden state. 

**Step 2.** The model makes a prediction 

Suppose after reading "The cat", it should predict 'Sat'. However, the model predicts "Ran" instead. so the model made an error. 

**Step 3.** Calculate the error (loss)

The model compares the output of the prediction and the correct answer. This produces a number called the loss. 

**Step 4** . Backpropagation 

Now the model asks "Which weights caused this mistake?". To answer that, it sends a gradient backward through the network. As shown on the image, the arrows go backward. The gradient flows from the output back through every previous hidden state until it reaches the weights.

**What is gradient?** 

The gradient is basically a set of instruction saying 'Increase or decrease this weight a little". The gradient tells each weight how much changing it would reduce the error. As it goes backward through many time steps, it keeps getting multiplied by small numbers. Starting from 1.0 : 

1.0 \* 0.5 = 0.5

0.5 \* 0.5 = 0.25

0.25 \* 0.5 = 0.125
.
.
.

0.0000001

After many steps, the learning signal is almost zero. That means the weights responsible for processing the first word receive almost no update. So the model doesn't learn much about the beginning of long sentences. 

In order to overcome these problems, researchers tried to increase more RAM, GPU, or more hidden units. It helped a bit but it didn't solve the vanishing graident, because the backpropagation through many time steps was unchanged. 

# The Transformer Architecture 

**The Transformer Architecture** 

The Transformer Architecture was introduced in the 2017 paper ['Attention is All You Need' (Vaswani et al)](https://arxiv.org/abs/1706.03762). The new architecture replaced sequential processing with the Attention Mechanism. 

**Self-Attention** : This allows a model to look at all tokens in a sequence simultaneously, creating context-aware embeddings. For example, the word "bank" would have different meanings depending on whether the context is about money or a river. 

**Query, Key, and Value (Q, K, V)** 

  -   Query (Q) asks what information is needed "Who has the information I need?"
-   Key (K) describes what information a token holds - "Here is what I know"
-   Value (V) is the actual information provided - providing the actual information once the best matches are found. 

**Encoder-Decoder Structure** 

-   The Encoder processes the input text to create rich representations. 
-   The Decoder generates the output, using Masked Self-Attention to look at previously generated tokens and Cross-Attention to pull information from the encoder. 

**Position Embedding** 

-   Transformers process all tokens at once, they require added position embeddings to understand the order of words in a sequence.

## Metrics After the Transformer

With the new architecture, there has been a significant move toward reference-free metrics and perplexity to overcome the high cost and limitation ofo relying on human labeled references required by BLUE and ROUGE. 

BLUE and ROUGE are reference-based, meaning they measure how well a model's translation or summary matches a human-provided reference text. However, they have a major problems such as high cost and time. 

-   **Reference-Free Metrics** allow us to assess a model's output without comparing it to a pre-written human answer

-   **Perplexity** is a metric that focuses on the probabilities output by the model itself to quantify how surprised it is by its own outputs. If a model is very confident and predicts a sequence of text with high probabilities, its perplexity will be low. That is, a lower perplexity score indicates better performance.
